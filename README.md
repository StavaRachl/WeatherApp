# 🌦️ WeatherApp — Telegram Weather Bot

## 📌 Описание проекта

**WeatherApp** — это Telegram-бот на Java, который показывает текущую погоду по названию города.

Пользователь отправляет команду:

```bash
/weather London
```

После чего бот получает данные о погоде через API и отправляет готовый ответ в Telegram.

| ---------------- | ------------------------------ |
| Java 26          | Основной язык проекта          |

# 🚀 Основные команды

| Команда            | Описание                 |
| ------------------ | ------------------------ |
| `/start`           | Приветственное сообщение |
| `/weather <город>` | Получение погоды         |

Пример:

```bash
/weather Tokyo

Город: Tokyo
 Температура: 27.05
 Влажность: 51
 Ветер: 6.32
 Описание: пасмурно
```

# 🔧 Запуск проекта

## 1. Клонирование

```bash
git clone https://github.com/StavaRaChl/WeatherApp.git
cd WeatherApp
```

## 2. Настройка `.env`

Создайте файл `.env`:

```env
BOT_TOKEN=your_telegram_token
BOT_USERNAME=your_bot_name
WEATHER_TOKEN=your_weather_api_key
```

---

## 3. Запуск

```bash
mvn clean install
mvn exec:java
```

---

# 🧠 Как работает бот

1. Пользователь отправляет команду в Telegram.
2. `CommandHandler` обрабатывает запрос.
3. Бот отправляет запрос к Weather API.
4. Полученные данные преобразуются в объект `Weather`.
5. `RenderService` формирует красивый ответ.
6. Бот отправляет сообщение пользователю.
